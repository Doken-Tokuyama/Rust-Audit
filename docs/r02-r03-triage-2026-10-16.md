## Criterion violation (1)

**`tokio-macros/src/entry.rs:558` (`parse_knobs`)** — R03 "placeholder `if false`
branch (dead stub path)".

The branch is the compile-time type-assertion idiom, in statement form:

```rust
if false {
    let _: &dyn ::core::future::Future<Output = #output_type> = &body;
}
```

The binding target is `_`: the block can have no runtime effect, so its only
purpose is that the compiler type-checks it — the same idiom as
`fn check<T: Send>() {}`, which ADR 0001 exempts (C3), and the surrounding code
comments it as a "Compile-time assertion" (C2). The finding's fix hint
("remove the placeholder branch") would delete a compile-time assertion.

**Recommended refinement** (next increment, cite this misfire): exempt an
`if false` body whose statements are only `_`-target bindings (`let _: … = …;`)
— the type-assertion idiom — or downgrade the claim to "dead `if false` branch
(compile-time assertion or placeholder: verify)". Goldens for tokio change by
exactly 1 (R03 30→29).

## Wording note (1 class)

**W1 — R03 "empty body (stub)" / "constant return (stubbed logic)" on
cfg/macro-gated no-op alternates** (tokio's feature-off metric hooks,
`inc_*` counters, loom mock doubles — the 19+10 class above). The factual part
of the claim is accurate (the body IS `{}` / a constant); the "(stub)" label
accuses intent the tool cannot see (the gating lives in a macro or a
complementary `#[cfg]` branch). Per the ADR's downgrade-the-claim rule the
message should read "empty body (no-op or stub: verify intent)". Classification
stays TP; this is a wording change, not a detection change.

The verifier extracts each function body from the raw source (naive
brace/string/comment-aware matching, independent of the tool's lexer) and
re-checks the ADR conditions mechanically: fixture exclusion (C5), test
attributes (C1), live calls in "cannot fail" bodies (C1, comments stripped),
duplicate arguments in raw text (C1), truly-empty bodies (C1), constant-return
shape (C1), parameter use/underscore/`#[allow]` (C1/C2). Automated results:
**0 violations** across all mechanically checkable claims; 3 duplicate claims
inconclusive due to extractor limits → re-derived by hand (above). Idiom and
intent cases (C2/C3) were judged manually — which is how the `if false`
violation was found.

### Appendix — triage_verify.py (complete, as run)

```python
"""Independent ADR-0001 re-verification of R02/R03 findings.

Re-derives each claim from the RAW workspace source (not the tool's parser):
a claim that cannot be reproduced from the artifact is a criterion violation.
"""
import collections
import json
import pathlib
import re

ROOTS = {"ripgrep": "/tmp/probe-rg", "tokio": "/tmp/probe-tokio"}
data = json.load(open("/tmp/triage-scan.json"))
# The dump's keys were swapped at capture time: 'ripgrep' holds tokio's scan.
SCANS = {"tokio": data["ripgrep"], "ripgrep": data["tokio"]}

CONST_RE = re.compile(
    r"(?:return\s+)?(?:true|false|-?\d+(?:\.\d+)?[a-z]*|\"[^\"\n]*\"|"
    r"'(?:\\.|[^\\'])'|Self|[A-Z][A-Z0-9_]{2,})\s*;?")
TEST_ATTR_RE = re.compile(
    r"#\[\s*(?:tokio::|async_std::|core::prelude::v1::)?"
    r"(?:test|bench|rstest|quickcheck|proptest)\b")


def fn_body(src, line, name):
    """Raw body of `fn name` at `line`; None when inconclusive."""
    lines = src.splitlines()
    idx = next((i for i in range(line - 1, min(line + 3, len(lines)))
                if re.search(r"\bfn\s+" + re.escape(name) + r"\b", lines[i])), None)
    if idx is None:
        return None
    text = "\n".join(lines[idx:])
    op = text.find("(", text.find(name))
    if op < 0:
        return None
    depth, j = 0, op
    while j < len(text):
        if text[j] == "(":
            depth += 1
        elif text[j] == ")":
            depth -= 1
            if depth == 0:
                break
        j += 1
    ob = text.find("{", j)
    if ob < 0:
        return None
    depth, k, in_str, in_com = 0, ob, False, ""
    while k < len(text):
        c = text[k]
        if in_str:
            if c == "\\":
                k += 2
                continue
            if c == '"':
                in_str = False
        elif in_com == "//":
            if c == "\n":
                in_com = ""
        elif in_com == "/*":
            if text.startswith("*/", k):
                in_com = ""
                k += 2
                continue
        elif c == '"':
            in_str = True
        elif text.startswith("//", k):
            in_com = "//"
        elif text.startswith("/*", k):
            in_com = "/*"
        elif c == "{":
            depth += 1
        elif c == "}":
            depth -= 1
            if depth == 0:
                return text[ob + 1:k]
        k += 1
    return None


def attrs_above(src, line):
    lines, out, i = src.splitlines(), [], line - 2
    while i >= 0 and (lines[i].strip().startswith(("#[", "//"))):
        out.append(lines[i].strip())
        i -= 1
    return " ".join(out)


def norm(s):
    return re.sub(r"\s+", " ", s).strip()


def bucket(x):
    m = x["message"]
    for key, name in (("cannot fail", "R02 no-oracle-HIGH"),
                     ("no direct oracle", "R02 no-oracle-LOW"),
                     ("Tautological", "R02 tautology"),
                     ("Generic test name", "R02 generic-name"),
                     ("Assertion roulette", "R02 roulette"),
                     ("Duplicate assertion", "R02 duplicate"),
                     ("Magic number", "R02 magic"),
                     ("#[ignore]", "R02 ignore"),
                     ("empty body", "R03 empty-body"),
                     ("always returns a constant", "R03 const-return"),
                     ("ignores all", "R03 params"),
                     ("if false", "R03 if-false")):
        if key in m:
            return name
    return "OTHER"


violations = []
inconclusive = collections.Counter()

for project, scan in SCANS.items():
    root = ROOTS[project]
    for x in scan["findings"]:
        if x["rule_id"] not in ("R02", "R03"):
            continue
        b = bucket(x)
        path = f"{root}/{x['file']}"
        if pathlib.Path(path).with_suffix(".stderr").exists():
            violations.append((project, b, x, "C5: fixture with .stderr sibling"))
            continue
        try:
            src = open(path, encoding="utf-8", errors="replace").read()
        except OSError:
            inconclusive[(project, b)] += 1
            continue
        body = fn_body(src, x["line"], x["function"] or "???")
        if body is None and x["function"]:
            inconclusive[(project, b)] += 1
        if x["rule_id"] == "R02":
            attrs = attrs_above(src, x["line"])
            if not TEST_ATTR_RE.search(attrs) and "/tests/" not in "/" + x["file"]:
                violations.append((project, b, x,
                                   "C1: 'Test …' claimed but fn has no test attribute"))
            if b == "R02 no-oracle-HIGH" and body is not None:
                live = re.sub(r"//[^\n]*", "", body)   # comments are not code
                if "(" in live:
                    violations.append((project, b, x,
                                       "C1: 'no call' false — body has a live call"))
            if b == "R02 duplicate" and body is not None:
                if norm(body).count(norm(x["evidence"])) < 2:
                    violations.append((project, b, x,
                                       "C1: duplicate args not reproduced in source"))
            if b == "R02 roulette" and body is not None:
                n = re.search(r": (\d+) assertions", x["message"])
                bare = 0
                for m in re.finditer(r"\bassert!\s*\(", body):
                    depth, j = 0, body.find("(", m.start())
                    while j < len(body):
                        if body[j] == "(":
                            depth += 1
                        elif body[j] == ")":
                            depth -= 1
                            if depth == 0:
                                break
                        j += 1
                    if not re.search(r",\s*\"", body[m.start():j]):
                        bare += 1
                if not n or str(bare) != n.group(1):
                    inconclusive[(project, b)] += 1
        else:  # R03
            if b == "R03 empty-body" and body is not None and body.strip():
                violations.append((project, b, x,
                                   "C1: 'empty body' false — body has content"))
            if b == "R03 const-return" and body is not None \
                    and not CONST_RE.fullmatch(body.strip()):
                violations.append((project, b, x,
                                   "C1: 'constant return' not reproduced"))
            if b == "R03 params":
                claimed = x["evidence"].replace("unused params: ", "").split(", ")
                for p in claimed:
                    if p.startswith("_") or p in ("self",):
                        violations.append((project, b, x,
                                           f"C2: '{p}' is an intentional underscore param"))
                    elif body is not None and re.search(r"\b" + re.escape(p) + r"\b", body):
                        violations.append((project, b, x,
                                           f"C1: param '{p}' IS used in the body"))
                if "unused_variables" in attrs_above(src, x["line"]):
                    violations.append((project, b, x,
                                       "C2: #[allow(unused_variables)] declares intent"))

print("== criterion violations ==", len(violations))
for p, b, x, why in violations[:40]:
    print(f"  [{p}] {b} {x['file']}:{x['line']} {x['function']!r} -> {why}")
print("== inconclusive (manual review) ==")
for k, n in sorted(inconclusive.items()):
    print(f"{n:5d}  {k}")
```
